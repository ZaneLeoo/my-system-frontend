# VXE 接入与组件验证

- 依赖：vxe-table 4.22.4、vxe-pc-ui 4.20.1、Element 渲染适配插件 4.4.3，均使用开源版本。
- 开发环境启动 `npm run dev`，登录后进入“VXE 组件演示”，地址为 `/demo/vxe`。生产环境不注册该路由。
- 页面调用 `useVxe()`，集中初始化中文、样式和 Element Plus 渲染器，并跟随系统明暗主题；VXE 随使用页面懒加载。
- 档案列表：100 条模拟记录，查询、排序和筛选作用于完整模拟数据集，再分页；导出按钮仅导出当前页 CSV。
- 分类树表：查看树形分类、展开和收起；编码与父子层级独立。
- 单据明细：测试 Element 编辑器、必填/数值校验、Enter/Tab 导航、行列拖拽、增删行、金额重算及 10/100/500 行显示。存在排序时暂停行拖拽。
- 所有示例均为内存数据，刷新重置；未实现业务保存、分类接口或业务导入。
- 区域选取、整块复制粘贴等企业版扩展未安装。XLSX 导出插件及业务文件导入在实际业务阶段再按需接入。
- 新业务页直接使用 VXE 官方类型、列配置、事件和插槽；先验证真实页面后再提炼业务封装。

官方资料：[VXE Table](https://github.com/x-extends/vxe-table)、[Element 适配插件](https://www.npmjs.com/package/@vxe-ui/plugin-render-element)。
