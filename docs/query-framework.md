# 通用查询组件

一期接入料品、采购订单列表。系统工具 → 查询管理直接打开数据目录；在业务表的“配置查询”操作进入对应查询对象。业务表格和编辑／详情保留原实现，新增查询组件不包装 VXE 表格。

`QueryPanel` 接收安全的 `QueryMetadata`、成功生效的基础值和高级条件，提交 `QuerySelection`。`ConditionGroup` 支持 AND／OR、EXISTS／NOT_EXISTS；`ConditionValueInput` 按字段类型渲染文本、十进制输入、日期、枚举与查询参照。后端仍校验全部条件。

`useQueryDefinition` 负责加载发布元数据、将原列表的列筛选条件和新增字段值组装成统一协议。常用区与列筛选共享基础值，高级条件作为独立组共同生效。业务页仍管理请求序号和成功快照，失败恢复查询、分页、排序指示；刷新、保存不提交查询草稿。

数字 0、布尔 false 保留。小数使用字符串，区间使用两个端点。查询选项与编辑 Picker 不同：允许停用、未删除档案，按当前业务列表权限读取，不额外要求维护或独立参照权限。单位、分类完整加载，料品和供应商远程分页；选择未加载的 ID 会批量回显，失败保留原值并提供重试。

查询配置保存草稿后才能预览和发布，进入预览标签会自动加载草稿查询界面与结果；无数据、无权限或失败都有明确提示。预览选项使用草稿定义。控件类型显示中文，来源分组与字段下拉显示中文名称、数据库名称及类型。常用查询字段通过手柄拖拽排序，保存草稿并发布后影响业务列表。字段标识与物理来源首次保存后固定，后续停用旧字段并新增标识。发布变化不会默默丢弃旧条件：旧请求由后端拒绝；显式刷新后，仍存在的失效条件必须由用户调整或重置。

管理和业务新接口见 `src/api/system/query.ts`，类型见 `src/types/api/system/query.ts`。新查询请求超时 15 秒；普通若依接口协议不变。个人／公共查询方案不在本期，不保存列偏好，不新增通用表格封装。
