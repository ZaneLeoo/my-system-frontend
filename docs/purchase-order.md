# 采购订单页面

- 菜单：采购管理 → 采购订单。列表使用 VXE，分页、筛选和排序走接口，支持列宽调整和列顺序拖拽。
- 编辑和详情为独立页：`/purchase/order-document/create`、`/:id/edit`、`/:id/detail`。
- 供应商使用 `SupplierPicker`，料品使用采购限定的 `ItemPicker`；支持批量加料品、复制、删除、上下移动和行手柄拖拽，每单最多 200 行。同料品可以多行，库存单位只读。
- 默认含税录入，也可首次保存前改为未税。只有录入口径的单价可编辑；其他单价、各行金额及总金额由服务端试算。税率为空需补填，可填零。
- 数量、单价和金额用字符串传输，数量和单价精度由服务端提供；首次保存后沿用本单规则。增删、修改和调序立即使旧试算失效，仅最新响应生效，失败可重试。
- 保存失败保留表单；未保存离开、重新加载时提醒。刷新保留已提交的列表条件。详情显示订单快照，档案更名不改写历史。
- 草稿可编辑／提交；提交后可撤回、审核或驳回；审核后可关闭。驳回、关闭要求填写原因，各动作独立授权并携带版本。
- 功能范围不含库存、到货、入库和付款，不增加通用表格封装或列偏好持久化。

接口及类型分别位于 `src/api/purchase/order.ts`、`src/types/api/purchase/order.ts`；页面位于 `src/views/purchase/order/`。
