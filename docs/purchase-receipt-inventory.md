# 采购入库与数量库存

- 采购入库采用 VXE 列表和独立编辑／详情页，入口在采购管理；库存管理提供余额与流水查询。
- 来源使用 PurchaseArrivalLinePicker：远程分页及排序、跨页选择、当前页全选、确认前复核，每次最多 100 行。第一批来源确定供应商，随后只允许同供应商；不同预计仓库可合并；取消不修改表单。
- 单据最多 200 行，数量用十进制字符串；拆分使用 BigInt 计算六位小数，避免二进制浮点误差。明细通过 WarehousePicker 选择实际仓库，默认带入来源的预计仓库；启用货位的行使用 LocationPicker，切换仓库显式清空货位。拆分后的来源＋仓库＋货位组合不能重复。
- 到货详情支持生成入库及查看关联入库；生成时重新加载可用量，不直接复制页面累计数。来源采用独立参照权限，仓库、货位参照使用已有独立权限。
- 订单列表和详情显示以订购量为准的入库进度；订单详情明细展示待审核入库、累计已入库及已到货未入库（包含待审核入库）。关联入库入口放在订单详情页并传入 `orderId`，入库列表分页、刷新、重置及筛选保留来源订单上下文，关闭上下文提示后返回全部入库单。
- 提交占用来源、审核增加库存、作废追加冲销；价格和成本不在本期范围内。详情显示保存快照，维护记录折叠展示。
- 保存失败保留表单；分页、排序、筛选和刷新使用已生效查询条件，最新请求生效，失败恢复成功数据对应状态；离开未保存表单时确认。
- 库存只读，不依赖档案维护或参照权限。余额可查看零值并跳转固定维度流水；流水包含原始与冲销记录，按权限追溯入库单。数量列固定右侧便于查看。
- 组件和页面不新增通用表格封装、不保存列偏好。测试脚本、宿主页、截图及验证数据不提交。

- 到货单的仓库显示为“预计入库仓库”；实际到货日期和数量含义不变。入库表头不再保存仓库，明细逐行保存仓库及货位管理方式；列表展示明细仓库摘要，按仓库查询匹配包含该仓库的整张单据。
