# 采购到货单

- 菜单：采购管理 → 采购到货单。列表使用 VXE，分页、单号／状态列筛选和排序走接口，支持列宽调整、六点手柄拖拽及来源订单关联筛选。
- 编辑及详情采用独立页 `/purchase/arrival-document/create`、`/:id/edit`、`/:id/detail`。通过 SupplierPicker、WarehousePicker 选择供应商和收货仓库；选择来源行后更换供应商需确认清空明细。
- `src/components/purchase/PurchaseOrderLinePicker/index.vue` 是来源订单行参照，使用独立订单参照权限。支持关键词、排序、接口分页、跨页选择、当前页全选、排除已带入来源、确认前复核，每次最多 100 行，整单最多 200 行。
- 采购订单详情提供“建立到货单”和“关联到货单”。建立时根据当前可用来源重新查询，不直接采用旧页面的额度。订单列表／详情显示独立到货进度及各行待审核、已确认、可新增到货数量。
- 草稿仅维护本次数量、行备注和业务行顺序，料品和单位取来源快照。保存失败保留表单，未保存离开或重新加载需确认；后台最终检查精度、日期、状态和剩余额度。
- 已提交提供撤回、审核和驳回；已审核提供作废，驳回和作废必填原因。提交占用额度、审核确认到货，任何状态操作携带旧版本；客户端不自行反写累计数。
- 详情直接展示保存快照，底部操作信息默认折叠。货位及库存更新由后续入库单处理。
- API 与类型分别位于 `src/api/purchase/arrival.ts`、`src/types/api/purchase/arrival.ts`，页面位于 `src/views/purchase/arrival/`。查询采用已生效条件及最新请求，失败保留上次成功结果并恢复查询指示。

- 表头“预计入库仓库”为选填项，可清空；未指定时列表、详情和入库来源参照显示“未指定”。空值不影响到货保存、提交或审核；生成入库时不预填仓库，须在入库明细选择实际仓库。
