# 仓库、货位与参照

仓库档案位于“基础资料 → 仓库档案”。通过“管理货位”进入该仓库固定上下文的货位列表，货位不能移动到其他仓库。仓库未启用货位管理时入口禁用；仓库停用后仍可维护原有货位，页面提示其不能被新选。

维护页面使用 VXE 接口分页、筛选、排序及列拖拽，编辑和详情使用抽屉。查询失败保留最近成功结果；刷新、保存沿用已生效条件；关闭未保存表单需要确认。仓库不维护地址和联系人，也不显示未实现的库存字段。

## 参照组件

`WarehousePicker`、`LocationPicker` 位于 `src/components/masterdata/` 对应目录。均为单选，支持远程编码／名称快选、VXE 分页弹窗、键盘选择、清空、禁用和失败重试。

```vue
<WarehousePicker v-model="form.warehouseId" @change="form.locationId = null" />
<LocationPicker v-model="form.locationId" :warehouse-id="form.warehouseId" />
```

`v-model` 为 `number | null`；`change` 为所选对象数组，清空时为空数组。初始化及重新回显不触发变更，弹窗取消不修改原值。组件兼容 Element Plus 表单禁用和 change 校验。

货位必须绑定所属仓库；未选仓库、父仓停用或未开启货位管理时禁用。调用方在用户更换仓库时显式清空货位。组件本身保留失效或不属于当前仓库的 ID 并提示，避免回显阶段静默修改表单。停用旧值带标识，不能被新选；候选搜索和确认均经服务端复核，业务保存仍需最终校验。

列表查询使用接口分页，不受 100 条候选总量限制。批量回显接口每次上限 100 项；当前组件单选，每次仅解析一个 ID。参照仅依赖独立参照权限及必要仓库上下文，不要求维护权限。
